# Aerodynamic Analysis

**Status:** The native OpenVSP geometry, VSPAERO input cases, and coefficient tables have not yet been uploaded.

- [openvsp/](openvsp/README.md): editable geometry and geometry-reference information.
- [vspaero/](vspaero/README.md): solver settings, case definitions, coefficient tables, and plots.

For each analysis, record geometry revision, OpenVSP/VSPAERO version, analysis method, mesh settings, angle-of-attack and sideslip ranges, Mach/Reynolds inputs where applicable, and moment reference point. State units and sign conventions.

Keep **Sref, bref, and Cref** beside the dataset. Aerodynamic reference dimensions and measured prototype dimensions must be labeled separately. Explain coefficient fitting and the mapping into the Gazebo LiftDrag blocks in [modeling.md](../docs/modeling.md).
